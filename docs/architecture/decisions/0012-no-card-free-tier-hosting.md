# ADR 0012: No-card free-tier hosting

- **Status:** Accepted
- **Date:** 2026-10-24

## Context

The owner gives no card to any provider.

## Decision

Neon (database), GitHub Actions (collection, CI, batch jobs), Render (API) and Vercel (web), all free without a card.

## Consequences

Limits to watch: Neon 0.5 GB, GitHub's 6 h job limit, Render free cold starts and 512 MB memory.
