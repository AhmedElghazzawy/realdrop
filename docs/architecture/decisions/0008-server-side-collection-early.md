# ADR 0008: Collection on a server from day 4

- **Status:** Accepted
- **Date:** 2026-10-24

## Context

Price history is the asset competitors cannot fake; every missing day is lost forever.

## Decision

Collection runs on a server by 27 Oct 2026 at the latest, not on a laptop.

## Consequences

Done 25 Oct. History accumulates independently of development.
