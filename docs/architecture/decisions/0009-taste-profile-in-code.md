# ADR 0009: Taste profile is plain code

- **Status:** Accepted (amended by 0014)
- **Date:** 2026-10-24

## Context

Personalisation must be explainable, cheap, deletable and testable.

## Decision

Rank with counters and simple vector similarity in code; explanations are templated, not generated.

## Consequences

With ADR 0014 the profile is explicit (chosen styles, fits, colours) and lives on the device at launch.
